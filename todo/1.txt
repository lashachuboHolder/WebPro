Part 1: Project Instructions
Overview
You will work in groups to create a small React + Express.js project (MVP). The main goal is to practice building simple, functional user interfaces and a basic
backend API. Each group must use GitHub for collaboration — all members should actively contribute code (frontend or backend).
⚠ Your project does NOT need to be hosted or deployed. Running locally is completely fine.

Figma Design Requirement
1. Go to figma.com/community and find a free UI design that matches your project idea.
2. Use that design as the visual reference for your React frontend.
3. Build your UI to match the Figma design as closely as possible.
4. Submit the link to the Figma file you used along with your project.
Each project below includes a Figma tip with recommended search keywords to help you find a good match.

What to Submit
GitHub repository link for your React + Express.js project.
GitHub usernames + real names of all group members.

How You Will Be Evaluated
Individual Evaluation
Your commits, pull requests, and overall contributions on GitHub.
Group Evaluation
Live project demo during the interim presentation.
Overall functionality and correct implementation of your MVP.
⚠ Presentation is only a demonstration. No slides, PowerPoint, or additional materials are required.
